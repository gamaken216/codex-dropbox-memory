Use this when starting Codex on any PC:

```text
Use the Dropbox Codex memory folder for this work.

First, look for the memory folder in likely Dropbox locations, such as:
1. C:\Users\[USERNAME]\Dropbox\Codexmemory
2. C:\Users\[USERNAME]\Dropbox\[WORKSPACE]\Codexmemory
3. D:\Dropbox\Codexmemory
4. D:\Users\[USERNAME]\Dropbox\Codexmemory

When you find it:
- Read memory.md.
- Read project files in projects/ when relevant.
- Save raw work notes in inbox/ if asked to log the session.
- Save durable project context in projects/.
- Keep memory.md short and promote only stable information.
```
